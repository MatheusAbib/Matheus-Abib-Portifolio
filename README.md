## 🏗️ Sobre Este Projeto

Este portfólio foi desenvolvido em **React** com as seguintes características:

- **Internacionalização:** Suporte completo para Português e Inglês
- **Responsividade:** Adaptado para todos os tamanhos de tela
- **Scroll Suave:** Implementado com Lenis
- **Componentização:** Código modular e reutilizável
- **CSS Organizado:** Estilos separados por componente
- **Hooks Customizados:** useLenis, usePortfolioScroll, useTranslation
